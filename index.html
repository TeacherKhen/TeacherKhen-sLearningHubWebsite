🎮 How to Utilize the Games

  1. Each interactive game uses a custom .json file to store its structure, data, and your specific progress.
  2. If you want to use your game data on another device, make sure to first click Export Data inside the game dashboard and save that generated .json file.
  3. Then, simply open this website layout on your target new device, run the game, and load the .json file right back into it to resume!

👨‍🏫 About Teacher Khen

Teaching English • Designing Lessons • Creating Learning Experiences

Hello! I'm Teacher Khen, an English teacher fond of designing creative lessons and finding new ways to make learning more interactive, meaningful, and enjoyable.

Over the years, teaching has become more than simply presenting lessons. I enjoy turning ideas into classroom activities, games, visual materials, and interactive experiences that encourage students to participate, communicate, and learn by doing.

This Learning Hub grew from that passion. Many of the resources found here are created to make everyday English lessons a little more exciting — whether you're reviewing vocabulary, practicing phonics, building sentences, or simply looking for a fun way to get your students involved.
